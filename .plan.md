# V2.5 — Lore Studio (Comic Universe)

## What We're Building

A full lore-to-comic pipeline built into LoreRich Vault. Users bring their ancestral stories (or write new ones), assemble a character cast, pick a genre + tone, and Groq AI generates a structured comic narrative — 6–8 panels with scene descriptions, dialogue, mood, and narrator captions. Comics can be saved, shared via a permanent 0G link, minted as tradable ERC721 NFTs, and used as the basis for collaborative crossover lores where multiple creators combine their universes.

Text-based panels (styled as dark academia comic cards — no image generation API needed). Character roles claimable off-chain via wallet signature.

## API Routes

### `POST /api/lore/generate`

**Pattern:** Identical to `/api/pitch/generate` — import `isRateLimited`, `hasInjection` from `@/lib/rateLimit`.

**System prompt (key excerpts):**
```
You are the LoreRich Comic Weaver, an ancient storyteller who transforms ancestral lore into mythic comic narratives.

Return ONLY valid JSON:
{
  "title": "evocative comic title",
  "tagline": "one punchy line, max 15 words",
  "theme": "the moral or thematic core",
  "characters": [{ "name", "expandedDescription", "traits": [] }],
  "panels": [{
    "number": 1,
    "scene": "visual description for artist, 1–2 sentences",
    "characters": ["name"],
    "dialogue": [{ "character": "name", "line": "text" }],
    "mood": "tense|joyful|mysterious|triumphant|melancholic|haunting",
    "caption": "narrator text or null"
  }]
}

Rules: 6–8 panels. Clear arc: setup → tension → resolution. Honor cultural context. No fabricated facts.
```

**Constraints:** sourceText max 3000 chars, characters max 5, each description max 200 chars.
**Rate limit:** 5 RPM/IP. **max_tokens:** 2048.

---

### `POST /api/lore/merge`

Same pattern. System prompt modified to receive two lore inputs and create a crossover narrative. Characters from both sides become a merged cast. **Rate limit:** 3 RPM/IP. **max_tokens:** 2500.

## `LoreComic.sol` (ERC721 — Tradable)

Comics are tradable community assets (NOT soulbound). Standard ERC721 transfer enabled.

```solidity
contract LoreComic is ERC721, AccessControl {
    struct ComicMeta {
        address   creator;
        address[] collaborators;
        string    zgRootHash;  // 0G blob of full LoreComic JSON
        uint256   mintedAt;
    }

    uint256 private _nextTokenId;
    mapping(uint256 => ComicMeta) public comics;
    mapping(uint256 => string) private _tokenURIs;

    event ComicMinted(uint256 indexed comicId, address indexed creator, string zgRootHash);

    constructor() ERC721("LoreRich Comic", "LCOMIC") {
        _grantRole(DEFAULT_ADMIN_ROLE, msg.sender);
    }

    function mint(
        address to,
        string calldata zgRootHash,
        string calldata uri,
        address[] calldata collaborators
    ) external returns (uint256 comicId);

    function tokenURI(uint256 tokenId) public view override returns (string memory);
    function totalComics() external view returns (uint256);
}
```

Gas estimate: ~130,000 (hardcode in frontend write call).

## Component Architecture

### `LorePanel.tsx`

Renders one comic panel as a styled dark academia card:

```
┌─────────────────────────────┐
│  PANEL 3  ·  [TENSE]        │  ← font-mono text-smoke/60 + text-brass/50
├─────────────────────────────┤
│  SCENE: [visual description]│  ← italic font-mono text-smoke/70
├─────────────────────────────┤
│  ADAEZE: "dialogue line"    │  ← brass/70 name + serif parchment line
│  ELDER:  "response"         │
├─────────────────────────────┤
│  [Caption narrator text]    │  ← only if caption; italic text-smoke/50
└─────────────────────────────┘
```

Classes: `vault-glass rounded-sm overflow-hidden border border-brass/15`

---

### `LoreComicViewer.tsx`

Full comic strip. Props: `{ comic: LoreComic; onSave?: () => void; onMint?: () => void }`.

Layout:
1. **Header** — title (font-serif text-2xl parchment), tagline (italic), genre badge, creator address
2. **Characters strip** — horizontal scroll of character chips: name + trait pills
3. **Panel grid** — `grid grid-cols-1 md:grid-cols-2 gap-4`; LorePanel components
4. **Theme block** — brass divider + `"The Lesson: [theme]"` in serif italic
5. **Action bar** — Save (localStorage) | Upload to 0G | Share (only after upload) | Mint NFT (only after upload + wallet connected)

---

### `CharacterBuilder.tsx`

Props: `{ value: LoreCharacter[]; onChange: (chars: LoreCharacter[]) => void }`.

- "Add Character" button → inline form slides open
- Fields: Name (required), Description (textarea, max 200), Traits (chip input Enter/comma, max 5), Wallet Address (optional, validated with `isAddress()` from viem)
- Saved characters shown as pills with hover-expand and ×-remove
- "Load from Registry" button — reads `lorelich_characters` from localStorage, shows past characters in a picker popover

## `/lore/page.tsx` Structure

Three tabs: `Generate` | `My Comics` | `Collab`

### Generate Tab
```
Step 1: Source Story
  ├─ [Select from vault] dropdown (useOwnerVaults → useVaultStories → pick)
  └─ OR [Paste story text] textarea (max 3000 chars, char counter)

Step 2: Characters
  └─ <CharacterBuilder> (max 5 characters)

Step 3: Niche + Tone
  ├─ Genre pills: Epic | Mythic | Mystery | Horror | Folklore | War Chronicle | Coming-of-Age | Romance
  ├─ Tone pills: Reverent | Haunting | Triumphant | Melancholic | Urgent | Mystical
  └─ Optional prompt: "Add anything specific…" textarea

[Generate Lore] button → loading skeleton → <LoreComicViewer>
```

### My Comics Tab
- Loads `lorelich_comics` from localStorage on mount
- Empty state: "No comics yet — generate your first lore above"
- Grid of comic cards: title, genre badge, N panels, character names (truncated), created date
- "View" → `LoreComicViewer` in modal overlay
- "Share" → copy `/lore/[zgRootHash]` (only if zgRootHash exists; else shows "Upload first")

### Collab Tab
```
Left: Your Lore
  ├─ Story textarea + CharacterBuilder
  └─ [Get My Seed] → copies JSON {sourceText, characters, ownerAddress} to clipboard

Right: Their Lore
  ├─ [Import Seed] → paste JSON → auto-fills story + characters
  └─ Preview: shows partner's character names

Genre + Optional merge note
[Generate Merged Lore] → LoreComicViewer with both creator addresses shown
```

## `/lore/[rootHash]/page.tsx` Structure

- `rootHash` = 0G root hash of the uploaded `LoreComic` JSON blob
- Fetches: `GET /api/download?rootHash=[rootHash]` → parses JSON → `LoreComic`
- Renders: `LoreComicViewer` (read-only, no save/mint actions)
- **Character claiming section** (below the comic):
  - Each character card shows: name, traits, claimed status
  - Unclaimed: "Claim Role" button → `wagmi.signMessage("I am [name] in lore [rootHash]")` → stores `{ address, sig }` in `lorelich_character_claims_[rootHash]` localStorage
  - Claimed: "🎭 Claimed by 0x1234…abcd" badge in brass
- OG meta: title + tagline for social sharing
